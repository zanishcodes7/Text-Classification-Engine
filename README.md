## 🏗️ Architecture & Core Strategy
The engine optimizes latency and computational cost by passing queries through a cascading 3-tier structure:
1. **Tier 1 (Regex Engine):** Ultra-fast pattern matching (<2ms) for deterministic keywords and intents.
2. **Tier 2 (Statistical ML):** TF-IDF Vectorization + Logistic Regression classifier for statistical pattern recognition.
3. **Tier 3 (LLM Fallback):** Semantic fallback model for complex or ambiguous natural language queries.
